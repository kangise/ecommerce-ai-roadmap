# Path A: AI in Daily Operations

> Last updated: 2026-08-04

## Overview

- **Audience**: sourcing, operations, advertising and support roles in e-commerce
- **Prerequisites**: basic operating experience (you know what an ASIN, PPC and FBA are)
- **Time**: 30 minutes a day, all modules in 2–4 weeks
- **Output**: a reusable AI workflow of your own

> No code. Use AI tools to make day-to-day operations several times faster
