# Boundary Conditions: ecom-pricing

When this skill should NOT be used. Generated from chapter boundary sections.

### From a8-pricing-strategy.md

- **你不是 Buy Box 的持有者。** 跟卖场景下的动态定价是一场消耗战，算法比谁都快且不需要利润。如果这个 ASIN 上有多个卖家在抢，价格战的终点是所有人都不赚钱。这种情况该做的是差异化（捆绑、独家变体、品牌备案）把自己挪出比价范围，不是把跟价做得更快。
- **成本结构还没算清。** 动态定价的下限是你的真实保本价。很多卖家的"成本"只算了采购和头程，漏了退货损耗、长期仓储、广告分摊、汇率波动。用错的下限跑自动调价，会稳定地在你以为赚钱的价位上亏钱。先把 [A11 的利润模型](a11-financial-analysis.md) 做实。
- **品类对价格不敏感。** 有品牌溢价、有专利、或者买家按功能而非价格筛选的品类，降价换不来销量，只是把利润让出去。判断方法很简单：把价格上下调 5% 各跑两周，看转化率有没有动。没动就说明这一章的杠杆在你这里不存在。
- **平台限制了调价频率或幅度。** 部分平台对短期内的价格波动有风控（可能触发审查、掉 Buy Box 资格、或者被判定为价格操纵）。上自动调价前先确认目标平台的规则，并给脚本设幅度和频率上限——这是安全阀，不是可选项。

### From a11-financial-analysis.md

- **平台费率刚变过。** 佣金、FBA 分档、仓储费、关税规则每年都调，模型记忆里的费率必然滞后。这一章的所有测算模板都必须用你从后台导出的当期费用明细做输入，不是让 AI"按经验"填。费率错一个百分点，利润率的结论就可能反过来。
- **AI 直接做算术。** 语言模型在多步数值计算上会出错，而且错得不明显。这一章的正确用法是让 AI 搭结构、列出该算哪些项、指出你漏了什么成本，具体数字用表格或脚本算。凡是让模型算出来的最终数，都要用计算器复核一遍。
- **成本项还没收集齐。** 退货损耗、跨境汇率波动、平台促销分摊、长期仓储、弃置费——这些在利润表里常年缺席，缺一项结论就偏。跑测算之前先把成本项清单对一遍，宁可某项填"未知"标出来，也别默认为 0。
- **你要的是税务或会计意见。** 增值税注册门槛、进项抵扣、转让定价、常设机构判定——这些是专业问题，且各国规则不同、变化频繁。这一章能帮你把数据整理成会计师能用的形式，不能替代那份意见。
