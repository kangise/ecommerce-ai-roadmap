# Constraints: ecom-applicability

This skill uses boundary conditions rather than numeric constraints. See references/boundaries.md for the 57 chapter-specific applicability rules.

The three-part decision rule (data sufficiency, tool availability, risk/reward) replaces any fixed numeric thresholds. Each chapter's boundary bullets carry its own qualitative triggers (e.g. "less than one year of sales history", "fewer than a few hundred reviews", "weekly savings under one hour"), which are evaluated per case rather than applied as global constants.
