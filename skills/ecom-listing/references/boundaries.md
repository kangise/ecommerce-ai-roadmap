# Boundary Conditions: ecom-listing

When this skill should NOT be used. Generated from chapter boundary sections.

### From a2-listing-optimization.md

- **产品本身没有差异化。** Listing 优化能把你的卖点讲清楚，讲不出你没有的卖点。和竞品同款同价同评分的产品，文案再好也只能拿到"同等条件下略优"的转化，不会改变竞争格局。这种情况该回到 [A1 选品](a1-product-research.md)，不是继续改五点。
- **关键词数据是猜的。** 这一章的模板都假设你手上有搜索量数据。没有 Helium 10 / Cerebro 这类工具时，让 AI"推荐关键词"得到的是它认为合理的词，不是真实有人搜的词。宁可用后台的搜索词报告（免费、真实、滞后一周），也别用模型凭空想的词。
- **主图和价格才是瓶颈。** 移动端上买家先看图和价，再看标题，很多人根本不展开五点。如果你的点击率正常但转化率低，问题大概率在图和评分上，改文案收益很小。先用后台的 Session/CVR 数据定位到底卡在哪一环。
- **品类受严格文案管制。** 保健品、医疗器械、儿童用品这些品类，能写什么由法规决定而不是由转化率决定。AI 生成的"高转化文案"经常越线——功效暗示、绝对化用语、未经认证的宣称。这些品类必须人工过一遍合规（见 [A6](a6-compliance.md)），文案纪律块只能拦住一部分。
